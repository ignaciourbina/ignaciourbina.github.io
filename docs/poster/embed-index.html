Working index

Poster embed index

Twelve standalone pages. Paste the block snippet into the iPoster content area, and the matching detail snippet into that block's expanded-content panel. iPoster handles moving between them; these pages carry no navigation of their own. The whole poster on one screen is at index.html.

Base URL

https://ignaciourbina.github.io/poster/

Sizing

Every page is responsive and scrolls internally, so width:100%; height:100% is right in a block and in an expanded panel alike. Never give the iframe a fixed pixel height.
