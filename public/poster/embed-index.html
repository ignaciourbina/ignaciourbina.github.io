Poster embed index

Six pages, one per block. Each holds both a summary view sized for the block and a detail view for when the block is enlarged; a button inside the page swaps between them. Paste one snippet per block and nothing else. The whole poster on one screen is at index.html.

Base URL

https://ignaciourbina.github.io/poster/

Sizing

Content areas in this template are 388 px wide and 251, 311 or 659 px tall. Every page is responsive and scrolls internally, so width:100%; height:100% is right both in the block and once enlarged. Never give the iframe a fixed pixel height.
